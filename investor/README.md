# Деловой пёс — презентация для инвестора (v8)

**Живая версия:** https://volkoovv.github.io/udc-presentation/investor/

Одна HTML-страница, в которой собраны обе выгрузки из Claude Design:
десктопная «Общая презентация v8 фото (инвестор)» и «Общая презентация v8
(мобильная)». 20 слайдов в обеих версиях, тексты перенесены символ в символ.

## Как это открывается

| Экран | Что показывается |
|---|---|
| ширина ≥ 1000 px и высота ≥ 560 px | **сцена**: слайд 1920×1080 масштабируется под окно |
| телефон, планшет, узкое/низкое окно | **лента**: те же 20 экранов вертикальным скроллом |
| печать / «сохранить в PDF» | 20 страниц 16:9, по слайду на страницу |

Режим выбирает CSS-медиазапрос, а не JS — без скриптов страница всё равно
открывается лентой и читается целиком.

## Навигация в режиме сцены

- `←` `→`, `Space`, `PageUp` / `PageDown`, `Home` / `End` — листать;
- `O` — обзор всех слайдов, `Esc` — закрыть; `F` — во весь экран;
- колесо мыши и свайп на тач-экране;
- нижняя панель: назад / вперёд / номер слайда (он же обзор) / ⊞ / ⛶;
- ссылка вида `…/investor/#s14` открывает конкретный слайд — и в сцене, и в ленте.

## Что внутри

| Файл | Роль |
|---|---|
| `index.html` | вся дека: разметка обеих версий, стили и рантайм (240 КБ, ~40 КБ в gzip) |
| `assets/photo/*` | 9 фотографий, каждая в WebP и JPEG (`<picture>` сам выбирает) |
| `assets/fonts/*` | Onest 400–800 и Golos Text 400–700, сабсет «кириллица + латиница + ₽ ↗» |
| `assets/cw/mark-bone.svg` | знак бренда, он же фавикон |
| `assets/og-cover.jpg` | обложка ссылки (Open Graph) для мессенджеров и почты |

**Внешних запросов нет вообще** — ни React, ни CDN, ни Google Fonts.
Современный браузер тянет 846 КБ на всю деку; фотографии подгружаются в
фоне после первого экрана, поэтому при листании ничего не «проявляется».
